# Customer Segmentation Analysis

## Objective
Group customers by purchasing behaviour using RFM analysis and K-Means clustering.

## Dataset
Online Retail II dataset.
Source:Source: [Kaggle - Online Retail II](https://www.kaggle.com/datasets/mashlyn/online-retail-ii-uci)
The CSV file is not included in this repository. Download it and save it in the project folder as `online_retail_II.csv`.

## Tools
Python, pandas, NumPy, Matplotlib, Seaborn, scikit-learn, Jupyter Notebook

## How to run
1. Install the required packages:
   `pip install pandas numpy matplotlib seaborn scikit-learn jupyter`
2. Download the dataset and place `online_retail_II.csv` beside the notebook.
3. Open and run `customer_segmentation_rfm.ipynb`.

## Method
- Cleaned the transaction data and prepared customer-level features.
- Calculated Recency, Frequency, and Monetary (RFM) values.
- Standardised the features and applied K-Means clustering.
- Compared cluster profiles and visualised the customer segments.
