# Retail Sales Exploratory Data Analysis

## Objective
Explore retail sales trends, customer demographics, and product categories using Python.

## Dataset
This project uses a 1,200-row synthetic sample CSV created for practice. It does not contain real Walmart or customer data.

## Tools
Python, pandas, matplotlib, seaborn, and Jupyter Notebook.

## Analysis
- Dataset inspection and numerical statistics
- Monthly and quarterly sales trends
- Customer age-group and gender distributions
- Top-selling products and revenue by category
- Correlation heatmap
- Monthly revenue by product category

## Key Findings
- Quarter 4 had the highest sales in this sample.
- Electronics had the highest category revenue.
- The 56-70 age group had the most sales records.
- Unit price and total amount had a positive correlation.

## Recommendations
1. Monitor inventory for high-revenue electronics products.
2. Test bundles or promotions for lower-revenue categories.
3. Plan inventory and campaigns before Quarter 4.
4. Use real customer data before making demographic marketing decisions.

## How to Run
Keep `retail_sales_sample.csv` in the same folder as the notebook. Open `retail_sales_eda.ipynb` in VS Code and run all cells.
